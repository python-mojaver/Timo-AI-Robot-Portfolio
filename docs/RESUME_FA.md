# متن پیشنهادی بخش پروژهٔ تیمو

**دستیار ربات تیمو با پایتون و هوش مصنوعی**

- توسعهٔ بک‌اند FastAPI و رابط وب برای گفتگو، پردازش گفتار و ارتباط با اپ اندروید ربات.
- پیاده‌سازی جریان ایجنت با LangGraph، حافظهٔ ماندگار SQLite و ابزارهای کاتالوگ، دانش تأییدشده و مقصدهای ثبت‌شده.
- یکپارچه‌سازی Groq Whisper، مدل گفتگو از طریق Groq یا n8n و تبدیل متن به گفتار؛ مدیریت قطع پاسخ و پاسخ‌های دیررس.
- توسعهٔ تشخیص چهره با OpenCV و YuNet/SFace و اتصال رویداد تشخیص به پیام خوشامدگویی.
- پیاده‌سازی مدیریت دانش و مقصدها با کلید مدیر و تست‌های خودکار برای مسیرهای اصلی.

**فناوری‌ها:** Python، FastAPI، LangGraph، SQLite، Groq، n8n، OpenCV، JavaScript، Android integration.

**Android:** https://github.com/python-mojaver/HTNRobotAssistant

**بک‌اند:** https://github.com/python-mojaver/Timo-AI-Robot-Portfolio

از عبارت‌های «یادگیری خودکار مدل»، «آموزش مدل از صفر»، «گفتگوی صوتی مستقیم بدون STT»، «حرکت کاملاً خودمختار» و «اعتبارسنجی فیزیکی با تست واحد» استفاده نشود؛ کد ارسالی چنین ادعاهایی را تأیید نمی‌کند. وضعیت تشخیص گفتار فارسی و سازگاری اپ Android با نسخهٔ واقعی دستگاه باید جداگانه روی سخت‌افزار بررسی شود.
